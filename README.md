# Cloudformation Coralogix AWS

This repo contains AWS Cloudformation templates utilised for Coralogix Integrations. Templates can be copied and executed directly via the AWS Console or using AWS CLI or other Cloudformation management utilities.

## Archived Lambda Integrations

Lambda integrations whose upstream source in [`coralogix-aws-serverless`](https://github.com/coralogix/coralogix-aws-serverless) is no longer maintained have been removed from `aws-integrations/lambda-integrations/`.

Their templates and documentation remain available for reference in the [`lambda-integrations-archive`](https://github.com/coralogix/cloudformation-coralogix-aws/tree/lambda-integrations-archive) branch.
