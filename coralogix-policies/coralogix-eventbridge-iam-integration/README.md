# EventBridge IAM Integration (Notification Center Cases)

The module will create a cross-account IAM role that allows Coralogix Notification Center to publish Cases to an EventBridge event bus through a [global endpoint](https://docs.aws.amazon.com/eventbridge/latest/userguide/eb-global-endpoints.html).

Requests sent through a global endpoint are signed with SigV4A and may be authorized in either of the endpoint's two Regions, so the role grants `events:PutEvents` on the event bus in both the primary Region (the provided `EventBusArn`) and the `SecondaryRegion` (derived automatically — by global-endpoint design the bus there has the same name and account). A primary-only grant fails with `AccessDeniedException` during global-endpoint failover.

> **Note**: this template is for the Coralogix **Notification Center Cases** integration. For the legacy **Alerts webhook** EventBridge integration use [coralogix-eventbridge-policy](../coralogix-eventbridge-policy) instead.

## Fields

| Parameter              | Description                                                                                                                                        | Default Value        | Required           |
|------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|----------------------|--------------------|
| EventBusArn            | The ARN of the primary event bus that will receive events via the PutEvents method.                                                                | n\a                  | :heavy_check_mark: |
| SecondaryRegion        | The failover Region of the EventBridge global endpoint. The event bus in this Region has the same name and account as the primary one.             | n\a                  | :heavy_check_mark: |
| RoleName               | Don't change it! It needs to match the one that was input on the Coralogix form. Corresponds to the name of the AWS IAM role that will be created. | cx_eventbridge_iam   |                    |
| ExternalId             | The external ID generated by Coralogix for this integration. It is required as the sts:ExternalId condition on the role trust policy.              | n\a                  | :heavy_check_mark: |
| CoralogixRegionAlias   | The Alias for the Coralogix region, possible options are [us1, us2, eu1, eu2, ap1, ap2, ap3, custom]                                               | n\a                  | :heavy_check_mark: |
| CustomCoralogixAccount | In case you want to use a custom coralogix account, enter the aws account id that you want to use.                                                 | n\a                  |                    |
| CustomCoralogixRole    | In case you want to use a custom coralogix role, enter the role name that you want to use.                                                         | n\a                  |                    |

Run the following command to deploy the integration:

```sh
aws cloudformation deploy --capabilities CAPABILITY_IAM CAPABILITY_NAMED_IAM --template-file template.yaml --stack-name <the name of the stack that will be deploy in aws> --parameter-overrides CoralogixRegionAlias=<coralogix account region> EventBusArn=<EventBusArn> SecondaryRegion=<SecondaryRegion> ExternalId=<ExternalId>
```
